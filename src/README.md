# Historical experiments

This directory preserves the original multi-state, p-bit and P-dit scripts and
their paths for reproducibility. These models are not the current R4C5 device
claim. Programmable device states and spatial readout have not been established.

The current entry point is `python -m smtj_ising --data-dir /path/to/R4C5`.
See the root README for the single-channel recorded-noise software Ising demo.
